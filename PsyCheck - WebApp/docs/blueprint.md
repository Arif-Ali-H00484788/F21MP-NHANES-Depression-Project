# **App Name**: PsyCheck

## Core Features:

- Animated Loading Screen: Implement a loading screen with a blinking app logo displayed before and after onboarding screens and between screen transitions.
- Standard Login/Sign-Up: Design standard login and sign-up pages for user authentication, leveraging components from Material-UI (MUI), Aceternity UI, NextUI, and Chakra UI.
- Lifestyle Tracker: Track daily lifestyle goals individually in detail linked to the date (food, water, sleep, exercise, habits, weight).
- PHQ-9 Chatbot: Implement a PHQ-9 questionnaire chatbot with conversational UI. The tool will also save progress and administer tailored interventions depending on score and history.
- Sentiment Analysis Tool: AI powered sentiment analysis tool that scans user's journal entries for depression markers. The tool will decide which entries need to be flagged based on a complex model.
- Daily Journal: A personal space to document daily thoughts and feelings through a journaling feature linked to specific dates.
- Visual Dashboard: Consolidate all user data (lifestyle, PHQ-9, journal) into a visual dashboard, displaying a personalized welcome message, a weekly lifestyle summary in list form, and graphical visualizations for each metric.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to evoke calmness and introspection.
- Background color: Light grey (#F0F0F0) to maintain a clean and uncluttered appearance, reducing visual noise.
- Accent color: Muted blue (#A9A9D0) for interactive elements, providing a gentle contrast and enhancing usability without overwhelming the user.
- Use clear and readable sans-serif fonts, ensuring high readability and reducing cognitive load for users.
- Utilize minimalist and intuitive icons to enhance usability and guide users through the app's features. These icons should align with a brain-based theme, incorporating subtle imagery related to cognitive processes and mental wellness.
- Incorporate subtle and calming animations to offer gentle feedback and improve the user experience. Animations should be used sparingly to avoid distraction and create a seamless and fluid interaction.
- Ensure a fully responsive design, guaranteeing a consistent user experience across various devices. Employ a clean and uncluttered layout with ample white space, promoting clarity and reducing visual clutter.
